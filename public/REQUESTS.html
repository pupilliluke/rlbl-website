NEW Admin Setup Speed-Ups (Fly Through Setup)

Recently added shortcuts so seasons/teams/players/games can be set up in minutes, not hours

  • A Bulk add teams → Paste one team name per line (optional comma-separated hex color), check "also link to current season", create all in one click. Admin → Teams → "Bulk Add Teams"
  • B Bulk add players → Paste one name per line (optional comma-separated display name), create all at once. Admin → Players → "Bulk Add Players"
  • C Link all unlinked teams → One button takes every base team not yet in the active season and links them in parallel. Shows count of unlinked.
  • D Smart form defaults → New game pre-fills season_id, next-unused week, and next Sunday's date. New season suggests next "Season N" name based on existing.
  • E Season clone → Pick a source season and copy all its team_seasons (team identity, display name, conference, colors) into the current season in one click. Rosters not copied.
  • F Bulk roster paste → In Teams & Rosters → Edit Roster, paste one player name per line. Matches by name (case-insensitive) and adds all matched. Reports unmatched names.
  • G Keyboard shortcuts → Press / to focus the team search, n to open Add modal (when no other modal is open). Esc closes modals; Ctrl/Cmd + Enter submits.
  • H Searchable dropdowns → All team and season selectors now support type-to-filter, keyboard navigation (Arrow keys, Enter, Esc), and a clear button. Replaces clunky native selects.
  • I Inline player create → In the player picker, type a new name → "+ Create player 'X'" appears at the bottom of the dropdown → one click creates and selects them.
  • J Color picker → Color fields now show a native color wheel paired with a hex input. Either updates the value.
  • K Search teams by player name → Admin Teams tab search box matches both team names and any player ever rostered on that team across all seasons.
